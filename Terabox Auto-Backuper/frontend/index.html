Importar lista (CSV)

Cole uma linha por item, no formato C:\Pasta\Arquivo; /Backup/Pasta. A origem pode ser pasta ou arquivo; o destino é sempre uma pasta no Terabox. Se o caminho ainda não existe, acrescente um terceiro campo pasta ou arquivo (sem ele, assume pasta). Linhas em branco e linhas começando com # são ignoradas.

Destino automático: cada arquivo volta para a pasta original do mapeamento correspondente, como configurado na aba Configuração. Pastas existentes são mescladas; arquivos com o mesmo caminho são substituídos. Nada fora dos arquivos selecionados é apagado.

Restauração

Quando desmarcado, o Restaurar substitui arquivos com o mesmo caminho sem pedir confirmação. O relatório final ainda mostra o que foi substituído.

Configuração no Terabox

O app salva um arquivo JSON no Terabox com os mapeamentos e os caminhos locais de cada computador. Ele nunca guarda cookies, tokens, senhas ou a chave de criptografia. Um atalho fixo na raiz (_terabox_autobackup_config.json) permite encontrar o arquivo mesmo se você mudar a pasta ou o nome.
